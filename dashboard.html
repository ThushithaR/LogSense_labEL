Novel technique: LogAwarePreTokenizer
Standard BERT shatters log entities into meaningless tokens:

192.168.1.50 → ['192','.','168','.','1','.','50']

Our pretokenizer replaces them before tokenization:

192.168.1.50 → [IP_ADDR]
sshd[3821] → sshd [PID]
0x7f3a1b → [HEX_VAL]
Training journey
✗ HDFS only → F1 0.71 (block-level signal, not line-level)
✗ BGL only → F1 0.99 (trivial first-token shortcut)
✓ BGL + HDFS + Synthetic → F1 0.864 (generalizes)
Early stopping at peak val F1. ROC-AUC 0.954 exceeds LogBERT baseline.
Security — Applied Cryptography Layer
SHA-256 Log Integrity
Every log line is hashed before classification. If a log is tampered with or forged, the hash will not match and the line is rejected. This prevents attackers from injecting fake "clean" logs to hide their tracks.
AES-256 Encryption
Sensitive log data (IPs, usernames, PIDs) is encrypted at rest. Only the classification pipeline can decrypt for analysis. This satisfies data privacy requirements and prevents unauthorized log access.
